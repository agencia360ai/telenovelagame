# Audio assets

These `.wav` files are **placeholder sound effects** generated by
`scripts/gen-audio.js` so the audio system works out of the box.

Replace any file with a real sound by **keeping the same filename** — the game
picks it up automatically (filenames are wired in `src/game/assets.ts`).

| File              | Used for                                  | Volume |
| ----------------- | ----------------------------------------- | ------ |
| `tap.wav`         | advancing a chat message                  | 0.4    |
| `ring.wav`        | incoming-call ring in the lobby           | 0.7    |
| `dispatch.wav`    | answering / choosing a unit (radio beep)  | 0.6    |
| `success.wav`     | correct dispatch                          | 0.7    |
| `fail.wav`        | wrong dispatch                            | 0.6    |
| `music-lobby.wav` | looping lobby ambience (background music) | 0.5    |

Supported formats: `.wav`, `.mp3`, `.m4a`, `.aac`. To add a brand-new sound,
drop the file here and register it in `src/game/assets.ts` (`SFX` or `MUSIC`).

Tune volumes in `SFX_VOLUME` / `MUSIC_VOLUME` in `src/game/assets.ts`.
